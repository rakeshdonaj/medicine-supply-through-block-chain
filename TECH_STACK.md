# Technical Stack Explanation

This project uses modern, industry-standard technologies. Here is an explanation for your viva/presentation:

### 1. Java (Servlets & JSP)
- **What is it?**: A powerful language for building secure web applications.
- **Why?**: Servlets handle the "logic" (the brain of the app), and JSP (JavaServer Pages) handles the "interface" (what the user sees).

### 2. Apache Tomcat 9
- **What is it?**: A Web Server that runs Java web applications.
- **Why?**: It is fast, lightweight, and specifically designed to run Servlets and JSPs.

### 3. MySQL
- **What is it?**: A Relational Database Management System (RDBMS).
- **Why?**: It stores all the user data, medicine details, and tracking history securely in tables.

### 4. SHA-1 Hashing (Blockchain Concept)
- **What is it?**: A mathematical algorithm that turns any text into a fixed-length string (a "hash").
- **Why?**: If even one letter of the medicine data is changed, the hash will completely change. This is how we know if someone tried to tamper with the data.

### 5. QR Code Technology
- **What is it?**: A 2D barcode that stores data.
- **Why?**: It allows patients to quickly scan a medicine bottle with their phone to verify its origin.
