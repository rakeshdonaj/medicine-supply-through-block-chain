# External Documentation - Project Analysis

## 1. Project Background
This project was developed as a final year engineering project. It addresses the lack of transparency in the pharmaceutical supply chain.

## 2. Problem Statement
Counterfeit medicines cost the industry $200 billion annually and lead to 1 million deaths per year. Traditional systems use paper records or simple databases that are easily manipulated.

## 3. Proposed Solution
A "Blockchain-lite" system where each transfer of medicine is cryptographically verified. No entity can claim they received a medicine they didn't, and no entity can pass off a fake medicine as a real one.

## 4. Key Security Features
- **SHA-1 Hashing**: Every item has a unique hash.
- **Asymmetric Key logic**: Using public/private key concepts for data decryption.
- **Role-Based Access**: Only verified Manufacturers can produce medicine.
- **Traceability**: A complete audit trail from manufacturer to patient.
